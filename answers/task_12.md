# Завдання 12. Одне слово, два значення (легке)

У застосунку доставки їжі слово «адреса» вживають у двох частинах системи. Для кур'єрів це місце доставки з під'їздом, поверхом і кодом домофона. Для бухгалтерії це юридична адреса клієнта для рахунку. Розробник пропонує одну спільну модель `Address` з усіма полями для всіх частин.

**Що потрібно зробити.** Поясніть, що таке обмежений контекст, чому спільна модель шкодить обом командам і як діяти натомість. Наведіть, як зв'язати дві моделі однієї реальної сутності.

**Обсяг:** 5-8 речень. Матеріал: лекція 6.

---

Відповідь:

Обмежений контекст (Bounded Context) — це явна межа (наприклад, окрема підсистема чи робота команди), у межах якої визначена й застосовна певна доменна модель. Спільна модель `Address` шкодить обидвом командам, тому що різні частини організації вкладають абсолютно різне значення в одне й те саме поняття, через що модель стає надто роздутою, а команди втрачають автономію. Замість спільної моделі слід створити окремі моделі для кожного контексту, які міститимуть лише необхідні для нього властивості. Для безпечного зв'язку між двома різними моделями однієї реальної сутності на межі контекстів застосовують антикорупційний шар (Anticorruption Layer), який здійснює взаємний переклад даних.
